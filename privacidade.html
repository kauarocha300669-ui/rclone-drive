Política de Privacidade

Este aplicativo é de uso pessoal e utiliza a API do Google Drive por meio do Rclone para realizar backups de arquivos.

Os dados acessados são utilizados exclusivamente pelo proprietário para armazenamento e gerenciamento de seus próprios arquivos.

O aplicativo não coleta, vende ou compartilha dados pessoais com terceiros.

O acesso aos arquivos é realizado mediante autorização da conta Google do proprietário.
